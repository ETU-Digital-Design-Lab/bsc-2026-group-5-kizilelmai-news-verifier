# D3: v17 Web Kanıtları Arşivi (Web Evidence Archive)

v17 çalıştırmasında seçilen toplam **187** web belgesi tam metinleri, kaynak URL'leri, çekim zaman damgaları (`ingested_at`) ve yayın tarihleriyle bu dizinde arşivlenmiştir.

Bu arşiv sayesinde v17 çalıştırması, gelecekteki arama motoru dalgalanmalarından bağımsız olarak çevrimdışı (offline) ve deterministik olarak %100 yeniden üretilebilir (reproducible) hale getirilmiştir.
