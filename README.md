# KızılelmAI, Türkçe doğal dil işleme (NLP) teknolojilerini kullanarak politikacıların, kamu figürlerinin veya haber kaynaklarının yanlış alıntılanan ifadelerini analiz eder ve orijinal, bağlamlı halini resmi kaynaklardan (Resmî Gazete, Anadolu Ajansı, İletişim Başkanlığı) doğrular.

Bu sayede, sosyal medyada sıkça karşılaşılan bilgi kirliliği ve bağlamdan koparılmış içeriklerin önüne geçmeyi hedefler.
